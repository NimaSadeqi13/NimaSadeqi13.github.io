# Nima Sadeqi — Architectural Portfolio

Bilingual Persian/English architecture portfolio with Next.js, GSAP ScrollTrigger, original project imagery and scroll-controlled film.

Public site: https://nimasadeqi13.github.io

## Development

Node.js24+, npm ci, npm run dev.

## Production

npm run lint && npm run build. Static output: out/. npm start previews on http://127.0.0.1:3101. GitHub Actions publishes the static output to GitHub Pages.

Only optimized, selected site media are included. Original archives, audit records and personal filesystem paths are excluded. Architectural work: Nima Sadeqi; brand graphic identities belong to their respective branding teams.
